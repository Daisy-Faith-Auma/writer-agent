# Scout profile

The news scout uses this file to decide which stories are relevant. Edit it any time.

## Topics I write about
- AI developer tools, APIs, and SDKs
- LLMs, agents, and AI coding tools
- Physical AI, robotics, and SLAM
- API design and developer experience
- Technical writing and documentation tooling
- Data engineering: Kafka, streaming, SQL, Python
- Data science education and learning to code
- African tech, fintech APIs, and developer communities

## Skip
- Funding rounds and acquisitions with no technical substance
- Crypto prices and trading
- Politics, unless it directly changes how developers build
- Sponsored items and job listings

## What makes a good topic for me
- Something I can explain, test, or build, not just react to
- A new tool or release I can try and turn into a tutorial
- A trend I have hands-on experience with
